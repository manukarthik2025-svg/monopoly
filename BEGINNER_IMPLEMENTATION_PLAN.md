# This plan has moved

This document has been replaced with a friendlier, more bite-sized version.

It used to be one long, dense document written more like a professional spec than a learning path — heavy on jargon (state machines, dataclasses, atomic saves) introduced without explanation, with no code examples and very large tasks. That made it a rough starting point for a first big project.

**Start here instead: [`quests/README.md`](quests/README.md)**

It breaks the same project into 37 small quests, each doable in one sitting, each with a plain-language explanation of any new idea, starter code with blanks to fill in, and a concrete way to test your work.

The full technical rules reference (exact prices, rent tables, every rule detail) still lives in [`PLAN.md`](PLAN.md) — the quests point to it whenever you need to look something up.
